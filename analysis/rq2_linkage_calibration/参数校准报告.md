# RQ2 匹配参数校准报告

文件夹：`analysis/rq2_oat/20261012_v3_factorial/`。挑选规则见 `selection_rule.md`，在判读与组合对照之前写定。逐对判读见 `pair_readings_270.csv`，每种组合的错误数见 `calibration_runs.csv`。

## 一、做法

1. **判读范围**：3,087种组合中，资格筛选后被配上过的全部配对，共270对（主设定150对，其他组合出现过的120对）。
2. **判读结果**：225对同一家，40对不同，5对不确定。不确定的5对是：Setzer Pharmacy地址上的药剂师个人条目；门牌号250与246的Cub；Aliveness Project的诊所服务条目；两条地址写作"Target Plaza South, 900 Nicollet Mall"的CVS与位于1000 Nicollet Mall的CVS #17626。
3. **错误数**：以Board记录为单位，错配加漏配；配给"不确定"的记录不计错误。
4. **挑选**：错误最少；并列时取间隔最大的组合（间隔指判读明确的配对中，得分与阈值的最小距离）；再并列时取最接近原设定的组合。

## 二、结果

**原主设定（0.8, 60, 0.85, 75）**：错配0，漏配11，间隔0.18。1,560种组合的错误数比它少。11个漏配全是同一地址上的药房：名称写法不同（例如"Cub - Maple Grove"与"SUPERVALU Pharmacies (dba) Cub Pharmacy"、"Lakes Pharmacy"与"Lake Cedar Pharmacy LLC"），或者解析地址时丢了门牌号（市中心Target店内的CVS）。其中4对的得分在74.07至74.82之间，只差不到1分。

**按写定规则直接选出的组合（1.5, 60, 0.85, 60）**：错误数为0，但间隔为0。在它下面，Target门店与店内CVS这一对（名称相似度0）恰好得60.0分，刚好压在阈值上。它的门牌号锁定失效，名称下限降到0。所有零错误的组合都是这种情况（34种，间隔全部为0）。

**对规则的一处补充**：剔除"有判读明确的配对恰好落在阈值上"的组合。得分正好等于阈值时，配不配得上取决于浮点数是否相等，这样的零错误站不住。补充后，错误数最少为1，选出的组合为：

| 参数 | 原设定 | 校准后 |
|---|---|---|
| 地址权重 | 0.8 | **1.2** |
| 门牌号分值（街道占比） | 60（40%） | **90（10%）** |
| 邮政编码系数 | 0.85 | **0.90** |
| 阈值 | 75 | **60** |

这组参数在270对上错配0、漏配1，间隔3.56。唯一的漏配是Target店内的CVS #16714：两条CVS记录的门牌号在解析时丢失，Target门店记录的名称相似度为0，只有名称下限降到0时才能配上。这组参数没有被强制要求满足任何设计规则，但两条规则都自然成立。

## 三、每个数现在怎么解释

- **为什么是这四个数**：在人工核对的270对上错误最少，而且离阈值最近的核对配对也有3.56分的余量。原设定的余量是0.18分。
- **地址权重1.2高于名称权重1.0**：资格筛选之后，清单里基本都是药房，地址是最可靠的证据。名称在法定名称、门店名和分店名之间变化很大（"Cub - Maple Grove"与"Cub Pharmacy"），只适合用来在同址的重复条目之间做选择。
- **门牌号90分、街道只占10%**：门牌号是一个干净的数字。街道字符串经常带格式噪声（"2635 Rice St Walgreens"与"2635 Rice Street"、"MN-7"与"Hwy 7"），只起确认作用。
- **门牌号锁定**：门牌号不同的配对最高得50.91分，比阈值低9.09分（原设定只低1.67分）。同一品牌同一条街上的不同门店因此分得更开。
- **邮政编码**：名称和地址完全一致而邮政编码不同的配对得90分，仍可配对。系数在0.70至0.90之间，筛选后的配对完全相同。其中取0.85时，一对邮政编码不同的核对配对离阈值只有0.20分；0.70、0.75、0.90的间隔都是3.56，0.90离原设定最近。
- **名称下限**：地址完全相同时，名称相似度达到12即可配对（邮政编码不同时为26.7）。同址的药剂师个人条目也会过线，但一对一分配会把Board记录配给药房本身的条目。

- **配对变化**：相对原设定新增11对，原有的150对全部保留。新增的11对中，10对判读为同一家，1对是不确定的Aliveness Project诊所条目。
- **筛选前多出的13个配对**：其中两个连接的是同一建筑里的非药房条目，一个是CVS店内的加密货币自助机，一个是影像研究中心与放射性药房PETNET。这正好说明资格筛选的作用。
- **重复名称结论**：重复名称的优势仍然成立，但Board内的差距从33.56个百分点缩小到21.71个百分点。原设定下，独立药房因为法定名称和店名差异更大，被严格的名称要求多漏掉了一部分。这一点论文里需要如实写。

## 五、稳健性与局限

- **不确定配对的处理**：把5对不确定都当作"不同"，选出的组合不变。都当作"同一家"，最优组合变成（1.2, 70, 0.85, 60），它的间隔只有0.21；校准后的组合在这种情况下多1个错误。
- **网格边界**：门牌号分值90和阈值60都在已声明网格的边界上。网格之外，更高的地址权重或更低的阈值可以消除剩下的那个错误（例如（2.0, 90, 0.90, 60）错误数为0，间隔6.67；（1.5, 90, 0.90, 55）错误数为0，间隔5.00），代价是名称下限降到0以下，同址而名称完全不同的记录也能配对。
- **判读依据**：判读只依据名称和地址，由分析者逐对完成。判读本身也是这次校准的输入，需要作者复核。
- **规则补充**：补充规则发生在看到写定规则的结果之后，论文中应如实交代。
