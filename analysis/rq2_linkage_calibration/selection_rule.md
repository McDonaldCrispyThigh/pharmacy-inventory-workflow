# 参数校准的挑选规则

写定时间：2026-10-12 22:00（America/Denver），在逐对判读完成、并把判读与任何参数组合对照之前写定。此后规则保持不变。

## 1. 候选组合

已在运行前确定的网格：地址权重9个值、门牌号分值7个值、邮政编码系数7个值、阈值7个值，共3,087种组合（表C35的取值）。

## 2. 判读范围

在任一组合下、资格筛选后被一对一分配配上过的全部配对，共270对（主设定的150对，加上其他组合下出现过的120对）。

## 3. 判读标准

逐对阅读两侧的名称、完整地址和邮政编码，给出三种判读之一：

- **同一家**：工作流记录指向Board执照对应的那家药房，或指向容纳这家药房的门店或机构（同一地址上的超市、大卖场或医疗机构）。
- **不同**：两条记录指向不同地点，或同一地址上互不相关的机构。
- **不确定**：仅凭名称和地址无法判断，包括同址的药剂师个人条目和同址的诊所服务条目。

## 4. 每种组合的错误数

以Board记录为单位计算。设 T_j 为与Board记录 j 判读为"同一家"的工作流记录集合。

- 组合把 j 配给判读为"不同"的工作流记录：计1个错配。
- 组合让 j 保持未匹配，而 T_j 非空：计1个漏配。
- 配给判读为"同一家"的记录，或配给判读为"不确定"的记录：不计错误。
- 只有"不确定"候选的 j 保持未匹配：不计错误。

错误数 = 错配 + 漏配。

## 5. 挑选

1. 错误数最少。
2. 并列时，取间隔最大的组合。间隔指所有判读为"同一家"或"不同"的配对中，得分与阈值之间的最小距离；间隔越大，结论对得分的小幅波动越稳定。
3. 仍然并列时，取与原设定（0.8, 60, 0.85, 75）相同的参数个数最多的组合。
4. 仍然并列时，取网格位置与原设定距离之和最小的组合。

## 6. 稳健性

把"不确定"全部当作"同一家"、再全部当作"不同"，各重算一次，报告选中的组合是否仍在错误数最少的组合之中。

## 7. 用途

按此规则选出的组合作为新的主设定候选，原设定作为敏感性分析保留。判读依据名称和地址，属于人工核对，用来校准参数和报告配对层面的准确率。
